# 🍅 Pomodoro: The Sequel Nobody Wanted
Yet another Pomodoro timer that literally nobody asked for, but I made it anyway because I was bored and wanted to play with pixel fonts. 
Does it work? Yes. 
Did the world need another one? Absolutely not. 
Do I care? Also no. 10/10 would procrastinate again.

# What is this?
A Pomodoro timer. You know, that productivity technique where you work for 25 minutes and then take a 5-minute break. Except mine has aesthetic themes and pixel fonts because apparently basic functionality wasn't enough for me.

# How it works
1) Pick a theme (this is the most important step)
2) Set your focus and break times (or stick with the defaults)
3) Press play
4) Watch numbers go down
5) Feel productive
6) Repeat until you actually get work done (optional)

# Why did I make this?
Great question. Next question.
Actually, I was bored and wanted to learn more about React hooks, state management and custom fonts. Also I needed a timer and figured "how hard could it be?" (It wasn't hard at all, which is why there are 47,000 of these on GitHub)
